# Tuya Developer Platform

> The Tuya Developer Platform is the central hub for IoT developers building connected smart devices with Tuya. It provides comprehensive documentation, SDKs, APIs, cloud development tools, app development kits, device development resources, mini program development (native + Ray framework), SmartUI component library, certification services, and AIoT solutions at scale. The platform spans 4,400+ documentation pages across English and Chinese.
